# 🏍️ Bike Rental Management System

## 📌 Project Overview
The Bike Rental Management System is a Java-based console application developed to manage bike rental operations efficiently. It allows administrators to manage bike details, customer information, rental records, return details, and payment transactions using MySQL database connectivity.

## 🚀 Features

### 🔐 Login Management
- Admin Login
- Customer Login
- Username and Password Authentication

### 🏍️ Bike Management
- Add New Bikes
- View Bike Details
- Update Bike Status
- Delete Bike Records

### 👤 Customer Management
- Add Customer Details
- View Customer Information
- Delete Customer Records

### 📋 Rental Management
- Add Rental Details
- View Rental Records
- Manage Customer and Bike Rental Information

### 🔄 Return Management
- Add Return Details
- View Return Information
- Record Late Fees

### 💳 Payment Management
- Add Payment Details
- View Payment History
- Delete Payment Records
- Store Payment Date and Payment Mode

## 🛠️ Technologies Used
- Java
- JDBC (Java Database Connectivity)
- MySQL
- SQL
- PreparedStatement
- OOP Concepts

## 🗄️ Database Details
Database Name: `bikes`

Main Tables:
- Admin
- Bike
- Customers
- Rentals
- ReturnDetails
- Payments
- customer_login

## ⚙️ Application Requirements
- Java JDK
- MySQL Server
- MySQL Connector/J
- Eclipse / IntelliJ IDEA / VS Code

## ▶️ How to Run the Project

1. Clone this repository.
2. Open the project in your Java IDE.
3. Create a MySQL database named `bikes`.
4. Create the required database tables.
5. Add the MySQL Connector/J library.
6. Configure your database username and password.
7. Run the `Bike.java` file.

## 💡 Key Enhancements
- Implemented JDBC connectivity to interact with MySQL.
- Used PreparedStatement for executing SQL queries.
- Applied Java OOP concepts for structured application development.
- Implemented CRUD operations for bike and customer management.
- Developed rental, return, and payment management modules.
- Added separate login functionality for administrators and customers.

## 🎯 Project Objective
To develop a simple and efficient bike rental application that reduces manual record management and simplifies bike rental, customer management, return tracking, and payment operations.
